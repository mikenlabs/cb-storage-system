Features

Everything a business hub needs to protect its data

CB Storage System combines storage, organisation and protection in one clean, secure platform.

Secure by design

Row-Level Security on every table means staff can only ever see and touch their own files, while administrators keep a safe overview of the whole hub.

Smart auto-categorisation

Upload anything and the system automatically sorts it into the right category — by file type and by name keywords like invoice, contract or report — keeping the hub organised with zero effort.

Duplicate detection

Every file is fingerprinted with a SHA-256 checksum. Re-upload the same file and the system instantly flags it as a duplicate — saving space and clutter.

Instant search & filters

Search by name, type, category or keyword across the whole hub, and filter files with one click. The right document is always seconds away.

Backup & recovery

Snapshot every file and its metadata with a single click, then restore lost data straight from a previous backup — duplicates are skipped automatically.

Complete audit trail

Every upload, download, delete, backup and restore is logged with who, when and what. Full visibility for administrators at all times.

How it works

Protected in three simple steps

From upload to backup, CB Storage System handles the hard work for you.

1

Upload

Drag & drop any document, image, software or archive into CB Storage System. Files up to 50 MB are accepted.

2

Organise

The system auto-categorises each file by type and keyword, flags duplicates and indexes everything for instant search.

3

Protect

Admins run snapshots anytime and restore data with one click if anything is ever lost.

Security

Multi-layer protection for peace of mind

CB Storage System was designed around data protection from the ground up.

  • Row-Level Security Every query is scoped to the authenticated user.
  • SHA-256 fingerprinting Checksums detect duplicates and protect data integrity.
  • Signed download links Private files are served through time-limited URLs.
  • Admin-only backups Backup and restore operations are restricted to admins.

About the project

An academic study in secure data storage

CB Storage System was built as a student research project to explore how small-scale computing business hubs can solve the real challenges of data storage, organisation and protection without expensive enterprise software.

The system demonstrates three core objectives: secure role-based access, intelligent file management, and automated backup with recovery — all implemented with a modern cloud stack.
